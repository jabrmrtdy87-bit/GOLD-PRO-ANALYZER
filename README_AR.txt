# محلل الذهب الاحترافي V2.3 — ملفات بناء أندرويد

هذا المجلد يحتوي ملفات تجهيز تطبيق GOLD PRO ANALYZER لبنائه بصيغة APK.

## محتويات المشروع
- `main.py`: برنامج Python الأصلي.
- `buildozer.spec`: إعدادات بناء تطبيق Android باستخدام Buildozer.

## بناء APK على Linux أو WSL2

1. ثبّت Python وpip وJava JDK وأدوات Android المطلوبة لـ Buildozer.
2. ثبّت Buildozer:
   `python3 -m pip install --user buildozer`
3. افتح الطرفية داخل مجلد المشروع.
4. نفّذ:
   `buildozer android debug`
5. بعد نجاح البناء ستجد ملف APK داخل مجلد `bin/`.

لإنشاء نسخة قابلة للنشر، راجع توثيق Buildozer لإعداد إصدار release وتوقيعه.

## ملاحظات مهمة
- التطبيق يحتاج اتصال إنترنت وصلاحية INTERNET.
- يلزم إدخال مفتاح Twelve Data API داخل التطبيق لجلب بيانات الذهب.
- لا يتصل التطبيق بوسيط تداول ولا ينفذ أوامر بيع أو شراء تلقائياً.
- لم يتم تضمين مفتاح API داخل الملفات.
- هذا المجلد هو مشروع البناء، وليس ملف APK جاهزاً للتثبيت.
- إعدادات Android SDK/NDK قد تحتاج تحديثاً حسب نسخة Buildozer وبيئة البناء المستخدمة.

## الواجهة العربية
تم ضبط الواجهة الافتراضية باللغة العربية، مع تضمين مكتبات تشكيل النص العربي واتجاه الكتابة من اليمين إلى اليسار.

## بناء APK باستخدام هاتف أندرويد فقط (GitHub Actions)

1. أنشئ حساباً في GitHub أو سجّل الدخول من متصفح الهاتف.
2. أنشئ مستودعاً جديداً (New repository).
3. فك ضغط ZIP وارفع جميع محتوياته إلى المستودع، مع التأكد من رفع مجلد `.github/workflows` أيضاً.
4. افتح تبويب Actions داخل المستودع.
5. اختر سير العمل: Build GOLD PRO ANALYZER APK.
6. اضغط Run workflow وانتظر انتهاء البناء بنجاح.
7. افتح نتيجة التشغيل (workflow run)، ثم نزّل Artifact باسم GOLD-PRO-ANALYZER-APK.
8. فك ضغط الملف الذي نزلته، ثم ثبّت APK على هاتفك. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

ملاحظة: بناء APK يتم على خوادم GitHub، وليس داخل الهاتف نفسه. قد تحتاج إلى حساب GitHub، وتخضع حدود الاستخدام المجاني لسياسات GitHub الحالية.
